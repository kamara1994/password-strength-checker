# Password Strength Checker 🛡️

## 📌 Project Description
This Python script evaluates password strength based on:
- Length
- Uppercase & lowercase letters
- Numbers
- Special characters

It provides feedback to help improve weak passwords.

## 🚀 Features
✔️ Checks password complexity  
✔️ Provides improvement suggestions  
✔️ Simple and lightweight
